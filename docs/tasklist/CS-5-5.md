# Tasklist: CS-5 -- Codebase Refactoring

**Ticket:** CS-5
**Status:** IMPLEMENT_STEP_OK
**Created:** 2026-03-01

## Context

Phase 5 is a comprehensive structural refactoring of the codebase. The goal is to reduce duplication, remove dead code, split large modules, and extract magic values -- without changing any observable behavior. Nine sub-tasks (5.1--5.9, with 5.9 optional) are each independently committable. Every sub-task must pass `cargo fmt --check`, `cargo clippy -- -D warnings`, and `cargo test` before it is committed.

Key files targeted: `src/indexer.rs` (2992 lines), `src/db.rs` (1468 lines), `src/commands/mod.rs`, `src/commands/perl.rs`, `src/commands/grep.rs`, `Cargo.toml`.

---

## Tasks

- [x] **Task 5.1 -- Remove Dead Dependencies and Dead-Code Suppression**

  Remove `grep-matcher = "0.1"` and `parking_lot = "0.12"` from `Cargo.toml` (never imported in `src/`). Remove `#![allow(dead_code)]` from line 1 of `src/db.rs`. Run `cargo clippy -- -D warnings` to surface any newly exposed dead-code warnings; fix each by removing the dead item or adding a targeted `#[allow(dead_code)]` with a justification comment.

  **Acceptance criteria:**
  1. `grep-matcher` and `parking_lot` no longer appear in `Cargo.toml`; `#![allow(dead_code)]` is removed from `src/db.rs`; `cargo build` succeeds.
  2. `cargo clippy -- -D warnings` and `cargo test` pass with zero warnings and zero failures after all surfaced dead-code items are resolved.

- [x] **Task 5.2 -- Extract "Index Not Found" Guard Helper**

  Add `pub fn open_db_or_warn(root: &Path) -> Result<Option<Connection>>` to `src/db.rs` with the exact signature and behavior specified in the plan. Replace all 24 copy-pasted guard blocks across the 9 command files (`index.rs` x6, `management.rs` x5, `modules.rs` x4, `android.rs` x2, `ios.rs` x2, `project_info.rs` x2, `files.rs` x1, `watch.rs` x1, `analysis.rs` x1) with the canonical pattern using `open_db_or_warn`.

  **Acceptance criteria:**
  1. `open_db_or_warn` exists in `src/db.rs`; no instance of the old copy-pasted guard pattern remains in any command file (verified by search); all 24 call sites use the helper.
  2. Each replaced command function produces identical observable behavior (same warning message, same early return) when the index DB is absent; `cargo test` passes.

- [x] **Task 5.3 -- Deduplicate DB Query Functions**

  Add `SearchResult::from_row(&rusqlite::Row) -> rusqlite::Result<SearchResult>` and `RefResult::from_row(&rusqlite::Row) -> rusqlite::Result<RefResult>` to `src/db.rs`. Replace all 15+ identical row-mapping closures with calls to these methods. Rename `SearchScope::none()` to `SearchScope::empty()` (the PRD specifies `empty()`; this is the one deviation to fix). Make each of the four non-scoped functions (`search_symbols`, `find_symbols_by_name`, `find_class_like`, `find_references`) a thin wrapper that calls its scoped counterpart with `SearchScope::empty()`.

  **Acceptance criteria:**
  1. `SearchScope::empty()` is the constructor name (no `none()` remains); `from_row` methods exist on both `SearchResult` and `RefResult`; no inline row-mapping closures duplicating the `from_row` logic remain.
  2. All existing query results are unchanged; `cargo test` passes with zero failures.

  **Acceptance criteria:**
  1. `search_files` contains no duplicated WalkBuilder/channel body; its implementation is a single call to `search_files_limited(root, pattern, extensions, usize::MAX, handler)`; the channel bound in `search_files_limited` is capped at `limit.min(10_000).max(1_000)`.
