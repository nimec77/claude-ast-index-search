No data flow changes. The parsing pipeline remains:

```
main.rs (CLI dispatch)
  -> commands/* (command handlers)
    -> indexer.rs (file walk + parallel parse)
      -> parsers/treesitter/* (AST parsing via LanguageParser trait)
        -> db.rs (SQLite storage)
```

The only changes are where functions are defined, not how data moves between them.

## Risks

### Active Risks

1. **Dart error recovery shared helpers (Medium)**
   - **Risk:** `find_first_identifier`, `find_first_type_identifier`, `find_descendant_by_kind` are used by both error-recovery and non-error-recovery code. Moving them to the submodule changes call sites throughout `dart.rs`.
   - **Mitigation:** Expose helpers with `pub(super)` in the error recovery module. Update all call sites in `dart.rs` to use `error_recovery::find_first_identifier(...)` etc. Compile and test after each change.

2. **`walk_body_declarations` visibility (Low)**
   - **Risk:** `walk_body_declarations` is currently private in `dart.rs` but called by `try_recover_from_error`. Must be made `pub(super)` for the submodule to access it.
   - **Mitigation:** Change `fn walk_body_declarations` to `pub(super) fn walk_body_declarations` in `dart.rs`. This is a visibility-only change with no behavioral impact.

3. **`management.rs` exceeds 1000 lines after 6.2.2 (Low)**
   - **Risk:** Adding `cmd_install_claude_plugin` (52 lines) to `management.rs` (957 lines) brings it to ~1009 lines.
   - **Mitigation:** Acceptable for this phase. The function is a natural fit for management commands. Can be addressed in a future phase if needed.

4. **Binary crate module imports for `cli.rs` (Low)**
   - **Risk:** `cli.rs` is a binary crate module, not a library crate module. It must import library items via `ast_index::db`, not `crate::db`.
   - **Mitigation:** Use `use ast_index::db;` in `cli.rs`. This is already the pattern used in `main.rs` today.

5. **Merge conflicts (Medium)**
   - **Risk:** This phase touches the largest files in the codebase, creating high merge conflict potential.
   - **Mitigation:** Complete all sub-tasks in a focused burst on a dedicated branch (`feature/cs-6-6-phase6`).

### Resolved Risks (from Research)

- **`find_capture` signature variations:** All 14 copies are byte-identical. No adaptation needed.
- **Test import scoping:** `use super::*;` works correctly with `#[path]` since the module parent relationship is preserved.
